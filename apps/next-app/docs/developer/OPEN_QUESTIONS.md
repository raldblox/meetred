# Open questions

Privacy and metadata:
- What privacy level should be the default for real-time sessions
- Should Meetred offer a relay-only mode to reduce metadata leakage

History and usability:
- What retention policy best balances privacy and user expectations
- Should users be able to export direct message history and room logs

Safety and moderation:
- What minimal moderation system protects users without centralizing too much power
- How should mature content labeling work in a public room

AI rooms:
- How should model provenance and safety be communicated to participants
- How to prevent accidental exposure of API keys and local endpoints
