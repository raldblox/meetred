# Tech stack

Meetred is a browser-first real-time app.

Typical components:
- Next.js and React for the web app and routing
- Tailwind CSS and HeroUI for UI components and theming
- lucide-react for icons
- libp2p for peer networking, discovery, and encrypted transports
- WebRTC for real-time media in calls and streams
- IndexedDB for local storage of identity and cached history

Deployment can evolve over time, for example adding TURN services or an SFU for scale.
