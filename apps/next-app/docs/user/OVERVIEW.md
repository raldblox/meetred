# Help

If you are new, read Start here first. It takes about a minute.

Common shortcuts:
- Want to understand room cards and invites? Read Public room.
- Missing DM history or confused about DMs? Read Direct messages and Identity.
- Want to host? Read Streams, Calls, or AI rooms.
- Something not working? Read Troubleshooting.
- Want to use Meetred safely? Read Safety.

Meetred is early. If something is confusing, your feedback helps us improve quickly.
