# AI rooms

AI rooms let you chat with an AI hosted by the room owner.

In an AI room, people chat while the host connects a model. Once connected, the AI replies in the same room.

## Joining an AI room

1. Click an AI room card or link.
2. If the AI is not ready yet, you will see a waiting state.
3. When the host connects the model, you can start chatting.

## Hosting an AI room

The host can connect either:
- A local model running on their machine
- An API-based model using their own API key

The host chooses the model. If the host disconnects, the AI room goes offline.

## API keys

If you use an API key, treat it like a password. Use it only on devices you trust, and revoke it if you suspect it was exposed.
