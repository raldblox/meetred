# Troubleshooting

If something does not work, try these quick fixes first:

1. Refresh the page.
2. Check your internet connection.
3. Try another modern browser.
4. Switch networks if calls or streams fail.

## The public room looks quiet

Meetred is built around live activity. If no one is active, you may see a quiet feed.
Post your room card or invite a friend to start activity.

## I cannot send messages

- Check if your browser is blocking connections.
- Try disabling extensions that block networking.

## Calls: camera or mic does not work

- Allow permissions in your browser settings.
- Close other tabs or apps using the camera.
- Rejoin the room.

## Streams: viewers cannot see the stream

- Confirm the host started the stream.
- Refresh and rejoin.
- Switch networks if the connection is unstable.

## AI rooms: the AI is not responding

- The host may not be connected to a model yet.
- If you are the host, reconnect the model and try again.
- If you use an API key, confirm it is valid and has quota.
